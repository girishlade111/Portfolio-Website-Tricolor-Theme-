# Portfolio Website — Tricolor Theme

A personal portfolio website with an Indian tricolor (saffron, white, green) inspired theme, designed for Girish Lade — developer, designer, and AI builder.

## Features

- **Hero section** — name, tagline, and a strong first-impression intro
- **About section** — background, education, and what he does
- **Skills showcase** — technologies and tools he works with
- **Projects section** — highlighted work and live demos
- **Contact section** — ways to reach him (email, social links)
- **Tricolor theme** — saffron/white/green color palette inspired by the Indian flag, with clean modern typography and responsive layout

## Tech Stack

- **HTML5** — semantic structure
- **CSS3** — custom styling, animations, and responsive design
- **JavaScript** — interactive elements and UI behavior
- **Tailwind CSS** — utility-first styling (CDN)
- **React** (via CDN) — componentized UI sections

## Quick Start

No build step required — this is a static site.

```bash
# Option 1: open directly
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows

# Option 2: serve locally (recommended)
npx serve .            # http://localhost:3000
# or
python3 -m http.server 8000
```

Then open the URL in your browser.

The site is fully static and deploys anywhere that serves HTML:

- **GitHub Pages** — enabled on the `main` branch (live URL in the repo homepage field)
